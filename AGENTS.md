# AGENTS

Este repositório usa agentes especializados para orientar arquitetura, implementação, revisão e compreensão técnica do projeto.

## Agentes principais

- pipeline-architect: arquitetura principal, roadmap e decisões de fronteira Python/Rust.
- planning-lead: planejamento, decomposição de trabalho e sequenciamento de entregas.
- technical-explainer: explicação didática do projeto com base no código real, cobrindo contexto técnico, arquitetural e decisões de implementação.

## Agentes de execução

- python-orchestrator: camada de orquestração em Python.
- rust-core-builder: implementação no núcleo Rust.
- benchmark-runner: validação de performance e benchmarks.
- security-auditor: revisão de segurança.
- code-reviewer: revisão de PRs e diffs.
- commiter: mensagens de commit e resumo de mudanças.
